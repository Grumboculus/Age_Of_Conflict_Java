# Not a Step Back
A game designed in Java using the Swing built in GUI library.

## Core Features
- Randomly Generated Maps
- Custom Nations
- Fully featured UI suite

## Purpose
This project was built over a standard American school year as a final project for AP Computer Science A. Originally I wanted to do a custom compiler for a programming language but due to project constraints the compiler was not green lit sadly.
